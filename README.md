# Ruby / Rails 読解力トレーニング問題集

「書く」のではなく「読む」力を鍛えるための問題集です。
**1日20分、3問**を1セットにしています。

## 1日の構成

| 形式 | 目安 | 問い方 | 鍛えられること |
|---|---|---|---|
| A. 出力予測 | 5分 | 「このコードは何を出力する？」 | Ruby の言語仕様の正確な理解（参照、スコープ、メソッド探索、引数） |
| B. コードレビュー | 7分 | 「このコードの問題点をすべて挙げよ」 | Rails の落とし穴を嗅ぎ分ける力（N+1、トランザクション、権限、タイムゾーン） |
| C. PRレビュー | 8分 | 「この diff を approve してよいか？」 | 変更の影響範囲と本番で起きることを想像する力 |

A は Ruby 3.3 で実行して解答を検証しています。B と C は「答えが1つに決まらない」ものも含むので、解答例の観点を自分の答えと突き合わせてください。
B には「似た API の違いを説明せよ」形式の問題が混ざることがあります。

## 使い方

1. その日のファイル（`days/dayNN.md`）を開く
2. 問題ごとに、**紙かエディタに自分の答えを書いてから** `解答・解説` を開く（頭の中だけだと後から「分かってた」になりがち）
3. 解説は「仕組み → 確認方法 → 修正例 → 読解のコツ」の順。B / C は自分が何個の観点を拾えたかを数える
4. `PROGRESS.md` に ○ / △ / × と一言メモを残す
5. △ と × は 1 週間後にもう一度解く

難易度の目安:

- ★☆☆ … 基本。間違えたら該当トピックの復習が必要
- ★★☆ … 実務で踏みやすい。レビューで指摘できれば合格
- ★★★ … 仕様の細部や複数要因の組み合わせ
