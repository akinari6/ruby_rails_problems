# Ruby / Rails 読解力トレーニング問題集

「書く」のではなく「読む」力を鍛えるための問題集です。
コードレビュー・障害調査・設計判断の場面で必要になる、次の3つの力を対象にします。

1. **挙動を正確に予測する力** — Ruby のセマンティクス（参照、スコープ、メソッド探索、引数）
2. **問題点を嗅ぎ分ける力** — Rails のよくある落とし穴（N+1、トランザクションとコールバック、権限、タイムゾーン）
3. **変更の影響範囲を読む力** — diff を見て「このPRを通していいか」を判断する

## 問題の形式

| 形式 | 問い方 | 鍛えられること | 置き場所 |
|---|---|---|---|
| A. 出力予測 | 「このコードは何を出力する？」 | Ruby の言語仕様の正確な理解 | `ruby/` |
| B. コードレビュー | 「このコードの問題点をすべて挙げよ」 | Rails の落とし穴・設計の勘所 | `rails/01_*` |
| C. PRレビュー | 「この diff を approve してよいか？理由は？」 | 影響範囲の読解、実務に近い判断 | `rails/02_*` |
| D. 違いの説明 | 「A と B の挙動の違いを説明せよ」 | 似た API の使い分け | 各章に混在 |

形式 A は Ruby 単体で実行して答え合わせができます（解答は実際に実行して検証済み）。
形式 B〜D は「答えが1つに決まらない」ものも含むので、解答例の観点を自分の答えと突き合わせてください。

## 使い方

1. 問題を読み、**声に出すか紙に書いて**自分の答えを確定させる（頭の中だけだと後から「分かってた」になりがち）
2. `<details>` を開いて解答と照合する
3. `PROGRESS.md` に ○ / △ / × と一言メモを残す
4. △ と × は 1 週間後にもう一度解く

難易度の目安:

- ★☆☆ … 基本。間違えたら該当トピックの復習が必要
- ★★☆ … 実務で踏みやすい。レビューで指摘できれば合格
- ★★★ … 仕様の細部や複数要因の組み合わせ

## 今後の追加予定（候補）

- Ruby: Enumerable の遅延評価と `lazy`、`method_missing` / `respond_to_missing?`、`Comparable` と `<=>`、例外の `retry` / `ensure` の評価順
- Rails: ActiveRecord のロック（楽観・悲観）、`scope` と `class method` の nil 返却、Strong Parameters のネスト、Turbo との `status:`、ActiveJob の冪等性、`has_many through` の `dependent:`
- 形式 C を増やす: マイグレーション diff（`add_index` のロック、`null: false` と既存データ）、`config/` 変更の影響

どの方向を厚くするかは `PROGRESS.md` の弱点傾向を見て決める想定です。
